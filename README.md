# Minhas Faltas UnB
#### Gerenciador de faltas de disciplinas da Universidade de Brasília
---
Este é um programa gerenciador de faltas das disciplinas da Universidade de Brasília. Esse projeto está sendo desenvolvido a partir de uma necessidade pessoal, que é a vontade de ter mais controle sobre as minhas faltas ao longo do semestre letivo. 

Ademais, alguns alunos foram questionados se eles gostariam que houvesse um meio mais fácil de gerenciar suas faltas já que elas não são registradas no SIGAA diariamente (alguns casos), eles responderam que também sentem a mesma necessidade que a minha. E isso me incentivou ainda mais fazer esse projeto e pretendo escalar ele sempre que der.
